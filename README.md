# Coffman Electric website

Standalone one-page site (plain HTML/CSS, no build step). Kept separate from the ranch website.

Files:
- `index.html` – the whole site
- `logo.png`, `work-*.jpg`, `fault-*.jpg` – logo and photos, mostly cropped from screenshots of their Facebook page (ask for original files for sharper versions)

To host: upload all the files in this folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, etc.) and point coffmanelectric.com at it.

## Confirm with the client before launch
- Service lists under Residential / Farm & Ranch / Commercial are typical electrician work; adjust to what they actually do.
- License number, email, business hours, reviews.
- The estimate form opens the visitor's texting app with their request pre-filled (no server needed). Swap for an email form service if they prefer email.
